sap-mcp-server — ツール一覧

English
環境
Noツール説明対象システムフル参照専用開発専用
1 sap_list_destinations 接続先の一覧を取得する Tool 共通
2 sap_use_destination セッション既定の接続先を切り替える Tool 共通
3 sap_current_destination 現在の既定接続先を表示する Tool 共通
4 sap_call_fm Function Module / BAPI を RFC で呼び出して実行する ABAP
5 sap_select_table テーブルを RFC_READ_TABLE 相当で読み、行を取得する ABAP
6 sap_adt_freestyle ADT のデータプレビューで自由形式 SQL を実行し、結果を取得する ABAP
7 sap_adt_osql ADT で Open SQL を実行し、結果を取得する ABAP
8 sap_adt_ddic DDIC オブジェクト（テーブル / CDS）を ADT 経由で SELECT * する ABAP
9 sap_abap_read_source ADT でプログラムや Function Module のソースを読む ABAP
10 sap_abap_write_source ADT でレポート / プログラムを作成・更新し、活性化する ABAP
11 sap_abap_delete_source ADT でプログラムや CDS DDL を削除する ABAP
12 sap_abap_write_fm ADT で Function Module を作成・更新し、活性化する ABAP
13 sap_create_transport Function Module を呼び出して移送リクエストを作成する ABAP
14 sap_release_transport Function Module を呼び出して移送リクエストを解放する ABAP
15 sap_abap_activate ADT でオブジェクトを活性化し、構文チェック結果を返す ABAP
16 sap_list_odata_services 公開されている OData サービスとエンティティセットを探す。名前の推測を防ぐ ABAP
17 sap_call_s4_api OData / REST を Destination 経由で呼び出す。任意の SICF パスも通る ABAP
18 sap_call_soap SOAP サービスを呼び出す。envelope は透過で送る ABAP
19 sap_call_ias_admin Admin API（SCIM）でユーザ・グループ・アプリを操作する。個人情報を扱う Cloud Identity Services (IAS)
20 sap_call_ips_job Jobs / JobLogs API でプロビジョニングジョブを確認・実行する。個人情報を扱う Cloud Identity Services (IPS)
21 sap_call_cf_api v3 API でアプリ・Org / Space・サービスを参照・操作する Cloud Foundry
22 sap_call_bwz_content CDM のサイト情報を参照し、業務コンテンツを zip でエクスポートする Build Work Zone
23 sap_call_ctms_api v2 API で移送のノード・キュー・インポートを操作する Cloud Transport Management
24 sap_call_forms_api REST API で帳票を一覧・生成する Forms Service by Adobe
25 sap_call_cis_api CIS Central API でアカウント・サブアカウント・エンタイトルメントを参照する BTP アカウント
26 sap_call_cpi_api 監査・監視 API でメッセージ処理ログや連携成果物を参照する Integration Suite
27 sap_call_ans_api REST API で条件・アクション・購読とイベントを操作する Alert Notification Service
28 sap_call_sbpa_api REST API でワークフロー定義とインスタンスを参照・操作する Build Process Automation
29 sap_call_datasphere_api 公開 REST / OData API でカタログ・接続・タスクチェーンを操作する Datasphere
30 sap_call_calm_api REST API でプロジェクト・タスク・アラート・サポートケースを操作する Cloud ALM
31 sap_call_btp_cli btp CLI をサーバ側で実行し、出力を返す（v2.106.1） BTP アカウント
32 sap_call_cf_cli cf CLI をサーバ側で実行し、出力を返す（v8.18.3） Cloud Foundry
33 sap_call_datasphere_cli datasphere CLI をサーバ側で実行し、出力を返す（v2026.13.0） Datasphere
34 sap_call_ibp_api OData API でマスタ・計画・在庫データを参照・登録する IBP
35 sap_call_sac_api REST / OData API でストーリー・モデル・データの入出力を操作する Analytics Cloud
36 app_call_jira_api REST API で課題の参照・作成・状態遷移・検索を行う Jira
37 app_call_smartdb_api REST API v3 で文書・ビュー・業務プロセスを操作する SmartDB
38 os_call_windows_ssh オンプレ Windows サーバで任意の OS コマンドを SSH 経由で実行する オンプレ Windows（JP1 Manager 等）
39 os_call_linux_ssh オンプレ Linux サーバで任意の OS コマンドを SSH 経由で実行する オンプレ Linux（Zabbix Server・S/4 アプリ/DB サーバ等）
40 os_call_jp1_command JP1/AJS3 - Manager の許可コマンド（参照・運用・定義・退避・サービス制御）を SSH 経由で実行する JP1/AJS3 - Manager（Windows）
41 app_call_zabbix_api Zabbix 7.0 の JSON-RPC API で監視設定・障害・メンテナンス期間を参照・操作する Zabbix Server 7.0（オンプレ）
42 sap_call_scc_api Cloud Connector の管理 API で接続状態と公開設定を参照・変更する Cloud Connector
